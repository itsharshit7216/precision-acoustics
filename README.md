# Precision Acoustics — Flagship Planar Magnetic Audio

A production-ready luxury landing page for audiophile planar magnetic headphones built with React, Vite, and Tailwind CSS.

## Features
- **Cinematic Hero & Value Proposition**: High-contrast typography, relatable acoustic analogies, and high-resolution studio imagery.
- **360° Visual Gallery & Inspection Mode**: Multi-angle studio gallery (Front profile, side dial, overhead arch, 50mm driver macro, velvet travel case) with full-screen inspection.
- **Interactive Experience Breakdown**: 3-step acoustic walkthrough covering planar magnetic transducers, hybrid ANC, and dual wireless/wired listening modes.
- **Complete Technical Specification Sheet**: Detailed acoustic, connectivity, battery, and in-box package data.
- **Single Transparent Pricing (INR)**: Single transparent package priced at ₹9,599 with automated GST calculation and free express air delivery across India.
- **Slide-out Cart Drawer**: Smooth 500ms slide transition with quantity controls and direct Sign Up / Log In checkout pathways.
- **Interactive Sarcastic Easter Egg**: Triggered on Sign Up / Log In click in the cart drawer.

## Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Custom Glassmorphism Design System
- **Icons**: Lucide React (100% SVG)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
git clone https://github.com/itsharshit7216/precision-acoustics.git
cd precision-acoustics
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
